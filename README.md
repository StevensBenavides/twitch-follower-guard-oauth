# Twitch Follower Guard OAuth

Página estática de callback para la app de Twitch de Twitch Follower Guard.

- `callback.html` atiende el redirect de OAuth.
- En Device Code Flow solo sirve como página de cancelación/placeholder.
- No contiene secretos ni almacena datos.

URL registrada en Twitch:

```text
https://stevensbenavides.github.io/twitch-follower-guard-oauth/callback.html
```
